1. **How Bluesky draws its logo on screenshots**
   作者注意到 Bluesky 中正常显示的 “Follow” 按钮，在 iPhone 截图里会神奇地变成 Bluesky Logo。追源码后发现，它利用 `UITextField.isSecureTextEntry` 的截图隐藏行为：真正的按钮被放在“敏感”图层里，截图时 iOS 自动将其隐藏，从而露出底下预先绘制的 Logo。一个很巧、也颇有争议的 iOS UI 技巧。

2. **Quake Shareware, a CD-ROM just a little too full**
   Fabien Sanglard 深挖 1996 年 Quake Shareware CD 的商业与 DRM 设计。由于 Quake 本身只有约 22 MiB，id Software 把大量完整游戏的加密版本也塞进 CD，希望用户电话付款后立即解锁；结果破解组仅 39 天就发布了 `QCRACK.EXE`。文章进一步逆向 TestDrive 解锁系统，发现所谓服务器“秘密”实际全部能在客户端本地计算，是很漂亮的一篇软件考古 + DRM 失败复盘。

## 重点分类

### Arduino / ESP32 / Raspberry Pi

本次前 30 条里，**没有直接涉及 Arduino、ESP32 或 Raspberry Pi 的条目**。当前首页的硬件/嵌入式方向主要集中在 Fairphone + postmarketOS、GPU Offload 和 Puppy PPE 等主题。

其中第 **3 条 Fairphone 6 + postmarketOS** 比较值得关注：文章不仅是在修 Linux 手机摄像头驱动，作者还明确计划长期尝试做 RISC-V Linux 手机，属于很典型的开源硬件/嵌入式社区项目。

### LLM / Agent

今天相关内容不少，我会优先看这几条：

- **7｜GPT-5.6 Sol 降价**：对 Agent 的实际意义主要是成本，而不是 benchmark。长上下文和高频工具调用工作流会非常敏感于 Token 单价。
- **8｜Copilot Autofix / Snowflake Jira**：今天 AI 安全方向最值得读的一条。它把“AI Coding 的错误”从代码质量问题推进到了供应链和自动修复安全问题。
- **12｜GPT-5.6 Sol Vision**：偏多模态/VLM 实际应用评测。
- **13｜AI;DR**：不是模型本身，而是 LLM 对阅读、写作和沟通方式的影响。
- **18｜Speko**：Voice AI 的模型路由层，概念上就是语音领域的 OpenRouter。
- **22｜Roboflow Playground**：适合实际比较 VLM / Computer Vision 模型，而不是只看静态排行榜。
- **23｜LLM tail latency**：今天 Agent 基础设施方向我最推荐的一篇。方案极其简单——请求复制两份抢最快结果——但生产数据证明对长尾延迟非常有效。
- **26｜Cursor + GitHub 故障**：可以从 Agent 基础设施依赖关系角度看。
- **30｜Qwen3.8 27B Artificial Analysis**：如果关注 27B 本地模型，这是今天最值得直接看数据的一条。

### 写作与博客

今天这个方向有两条尤其明显：

- **13｜AI;DR**：直接讨论 AI 生成、AI 摘要之后“写”和“读”发生了什么。如果大量信息从 AI 生成直接流向 AI 总结，人为什么还要写完整文本，是一个很值得继续想的问题。

今天个人站内容很多，质量也不错，我会重点推荐：

- **1｜Tim Marinin — How Bluesky draws its logo on screenshots**  
  今天短技术博客首推。起点只是“为什么截图和屏幕上看到的不一样”，最后一路追到 React Native package 和 UIKit 的 secure text behavior。非常典型的 curiosity-driven 技术写作。
- **2｜Fabien Sanglard — Quake Shareware, a CD-ROM just a little too full**  
  今天独立博客整体首推。Fabien Sanglard 很擅长把软件考古写成技术侦探故事：找老 CD、Usenet 记录、文件格式，再真正逆向程序验证历史叙述。
- **3｜Catcrafts — Fairphone 6 + postmarketOS**  
  不只是“宣布驱动能用了”，作者把还没做完的部分、失败点、社区协作、资金使用乃至未来做 RISC-V 手机的想法都直接写出来，很有个人 Hacker 日志的质感。
- **9｜Nemanja Trifunovic — The Road to MS-DOS 2.0**  
  适合喜欢计算机史的独立长文。它不是简单列版本功能，而是把 DOS 的演化放回当时 PC 软件生态里看。
- **21｜Amos Dudley — Puppy PPE**  
  很典型的 maker 独立博客：有需求、有扫描、有 CAD、有制造、有实际失败，而且最终结论不是“项目大获成功”，而是诚实记录产品在真实环境里的问题。
- **25｜Al Sweigart — Intriguing Stories in Computer Science**  
  属于“长期个人网站作为知识索引”的好例子。作者明确说最初用 LLM 辅助生成候选，但自己逐条检查、修正链接，最后把它变成可继续探索的阅读地图。
